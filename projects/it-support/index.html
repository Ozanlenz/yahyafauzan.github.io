Project Overview

IT Support Lab merupakan dokumentasi pekerjaan teknis yang menggambarkan proses penanganan perangkat dan infrastruktur IT dari sisi end-user support hingga infrastruktur jaringan.


Dokumentasi mencakup troubleshooting hardware dan software, instalasi sistem operasi, printer support, server maintenance, pemasangan access point, CCTV, perangkat jaringan, infrastruktur ISP, serta network cabling dan uplink.

Technical Scope

Ruang lingkup pekerjaan yang terdokumentasi dalam project ini mencakup beberapa area teknis berikut.

End-User Computing

Troubleshooting komputer dan laptop, instalasi sistem operasi, serta penanganan permasalahan software.

Hardware Support

Pemeriksaan dan penanganan hardware komputer serta laptop untuk membantu memulihkan fungsi perangkat.

Infrastructure Support

Maintenance server serta dukungan terhadap perangkat dan infrastructure IT.

Network Support

Pemasangan access point, network cabling, uplink, HTB dan infrastructure ISP.

Peripheral Support

Troubleshooting dan perbaikan printer serta perangkat pendukung kegiatan operasional.

Supporting Systems

Pemasangan CCTV serta persiapan perangkat Zoom dan sound system untuk kebutuhan kegiatan.
