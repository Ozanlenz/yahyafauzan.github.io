PROJECT 01

MikroTik Network Lab

Project pembelajaran jaringan menggunakan MikroTik RouterOS dengan implementasi DHCP, VLAN, Firewall, NAT, Routing, Hotspot, VPN, Queue, dan Wireless dalam satu project terintegrasi.

MikroTik Networking RouterOS Firewall VPN

Project Overview

Tujuan

Membangun dan mengonfigurasi jaringan menggunakan MikroTik sebagai perangkat utama untuk mempraktikkan konfigurasi jaringan dan pengelolaan traffic.

Environment

  • MikroTik RB941-2nD
  • RouterOS 6.48.6
  • WinBox / RouterOS
  • WAN melalui ether1
  • LAN melalui bridge-LAN
  • Wireless melalui wlan1

Network Segmentation

LAN 192.168.10.0/24
STAFF VLAN 10 · 192.168.20.0/24
GUEST VLAN 20 · 192.168.30.0/24
CCTV VLAN 30 · 192.168.40.0/24
Wi-Fi 192.168.18.0/24
VPN Pool 192.168.50.0/24

Network Implementation

DHCP Konfigurasi DHCP untuk menyediakan alamat IP secara otomatis pada jaringan yang digunakan.
VLAN Segmentasi jaringan untuk STAFF, GUEST, dan CCTV.
Firewall Pengaturan traffic menggunakan firewall filter dan mangle.
NAT Konfigurasi Network Address Translation untuk kebutuhan akses jaringan.
Routing Pengaturan jalur komunikasi antar jaringan.
Queue Pengaturan bandwidth menggunakan Simple Queue.
Hotspot Implementasi layanan Hotspot pada jaringan.
VPN Implementasi L2TP/IPsec VPN untuk akses jaringan.
Wireless Konfigurasi jaringan wireless melalui interface wlan1.

Documentation

Dokumentasi visual project akan ditempatkan di bagian ini menggunakan screenshot konfigurasi MikroTik, topologi, dan hasil pengujian.

Dokumentasi akan disusun berdasarkan praktik project MikroTik yang telah dikerjakan.

Project Result

Project menghasilkan konfigurasi jaringan MikroTik yang mencakup segmentasi jaringan, DHCP, Firewall, NAT, Routing, bandwidth management, Hotspot, VPN, dan Wireless.
